# Undertale Yellow Randomizer Setup Guide

### Required Software

- Undertale Yellow AP Version from the Release GitHub
- Archipelago from the [Archipelago Releases Page](https://github.com/ArchipelagoMW/Archipelago/releases)

### First time setup
I have gotten permission to distribute the patched game files, so the setup is now even simpler than before
The setup instructions are as follows:

- STEP 1: Download Undertale Yellow AP.zip from the Releases Tab
- STEP 2: Extract the file
- STEP 3: Run Undertale Yellow.exe and enjoy!

**Linux Users**: For Linux users, however, I have not been able to test it. You will need to run the
game from Proton or Wine as this is built off the Windows version. You may also need to redirect the client
to the correct save file directory using `/savepath` command. The save is located in `*/users/USERNAME/Appdata/local/Undertale_Yellow`,
with I believe that first part depending on what you use to run the game.
